# PKM-DES FRD Traceability

PKM-DES is currently a research-presentation MVP. Its deployment is a temporary client preview intended to demonstrate the proposed digital enrollment workflow. It is not yet an operational replacement for PKM's official enrollment process.

This matrix compares the available Functional Requirements Documentation (FRD) with the current codebase. It distinguishes working demonstration behavior from partial implementation, visible placeholders, deferred institutional workflows, and items that require client confirmation. A browser-print output is referred to here as a **draft registration form**; it is not an official Certificate of Registration (COR).
