# PKM-DES Source Document Register

This register identifies the client-supplied artifacts used to inform the PKM-DES research MVP. The original PDFs and workbooks are intentionally excluded from the public repository because they are client source materials, may contain institutional information, and in some cases may include real-looking sample data. This document records their purpose and the tracked files that reflect their use.

| Document name | Purpose | How it influenced the implementation | Tracked in Git | Relevant tracked implementation or documentation files |
| --- | --- | --- | --- | --- |
| `About Us.pdf` | PKM institutional identity and public information reference. | Informed the About Us content, including PKM identity, vision, mission, goals, and contact information. | No - original client artifact is excluded. | `app/about/page.tsx`; `lib/constants/pkm.ts`; `README.md` |
| `Subjects.pdf` | Initial BSAIS curriculum reference. | Informed the 56 BSAIS curriculum subject rows used by the program curriculum reference and legacy subject seed. The current generic enrollment path requires an explicit active standard-load configuration and does not use this curriculum table as a BSAIS-only fallback. | No - original client artifact is excluded. | `lib/constants/subjects.ts`; `app/student/subjects/page.tsx`; `supabase/seed.sql`; `scripts/sqlite/init-dev-db.mjs`; `docs/dev/SUPABASE_SETUP.md` |
| `FRD1.pdf` | Original functional requirements and manual-enrollment-process reference. | Informed the MVP workflow, output expectations, placeholder boundaries, and traceability classifications. | No - original client artifact is excluded. | `README.md`; `docs/reference/FRD_TRACEABILITY.md`; `docs/reference/MVP_SCOPE.md` |
| `Joshua.pdf` | Functional requirements documentation for the proposed public, student, and admin modules. | Informed the planned navigation, account behavior, enrollment flow, empty states, and missing-information warnings documented for the MVP. | No - original client artifact is excluded. | `README.md`; `docs/reference/FRD_TRACEABILITY.md`; `docs/reference/MVP_SCOPE.md` |
| `LIST OF COURSES FOR 2ND SEM AY 25-26.xlsx` | Client-provided course-enrollment source for AY 2025-2026, 2nd Semester. | Informed the 245 unique course-offering rows for 10 canonical programs and the 36 complete active standard-load configurations used by the current MVP term. The duplicate BSAIS blocks collapse to 25 unique logical rows; incomplete BSAIS 4th Year, BSMA 4th Year, and CRIM upper-year combinations remain unavailable. | No - original client artifact is excluded. | `supabase/migrations/20260730000001_multi_program_course_offerings.sql`; `supabase/migrations/20260803000001_activate_workbook_enrollment_term.sql`; `lib/course-offerings/manifest.ts`; `app/student/subjects/page.tsx`; `docs/dev/SUPABASE_SETUP.md` |
| `REGISTRATION FORM 4G.xlsx` | Sample registration-form layout reference. | Informed the browser-print draft registration form layout. Its student-list data is not imported, seeded, or treated as curriculum data. | No - original client artifact is excluded. | `components/print/registration-form.tsx`; `docs/reference/REGISTRATION_FORM_SAMPLE_SCOPE.md`; `docs/reference/MVP_SCOPE.md` |

The register does not make any client artifact public or convert it into an approved institutional policy. It only records how the research MVP used the supplied materials.
